導入機能ガイド操作マニュアル

機能ガイド

曲の拍に合わせて演出を出し、音を聴きながらタイミングを調整するための Unity 拡張です。Tools → Particle Live Toolkit で編集中のライブを選び、曲の BPM を設定します。

音に合わせてキーを打つ、3つの操作

拍に合わせて編集位置を移動

Animation で Alt + ← / → を押すと、再生ヘッドが曲の BPM に合わせて4分音符ひとつ分移動します。左矢印で戻り、右矢印で進みます。

Shift も押すと 1小節、Ctrl も押すと 16分音符に移動幅が変わります。

出したい瞬間にオン・オフを記録

Hierarchy で演出オブジェクトを選び、Animation で出現させたいフレームに合わせて Ctrl + R。1フレーム前にオフ、現在のフレームにオンのキーが入ります。

たとえば 120 フレームで押すと、119 でオフ、120 でオンになります。先頭の 0 フレームではオンだけを記録します。

スペース長押しで聴き直す

Animation または Timeline で確認したい位置に合わせ、スペース を長押し。押している間だけ再生し、離すと開始位置に戻ります。

キーを少しずらした後も、同じ位置から音と演出のタイミングを確かめられます。短く押すと通常の再生・停止です。

ライブの準備と音合わせ演出の作成と整理確認と編集の再開

ライブの準備と音合わせ

音源付きのシーンを作る
Project → ライブを生成。曲と BPM を指定すると、新しいシーンの Timeline に音源とメインのアニメーションクリップが並びます。
小節や音符の長さを秒数でコピー
よく使う項目 → 秒数コピーで「1小節」や「4分」を選び、粒子の寿命などの秒数欄に貼り付けます。ほかの音符や倍率は Beat で選べます。
すでに打ったキーを拍に揃える
Animation でキーを選び、Beat Snap → 選択キーを拍に合わせるを押すと、選んだキー自体が指定した音符の位置へ移動します。
点滅や動きを繰り返す
キーを選び、よく使う項目 → 現在の範囲を取得。「ビートで4回」を押すたびに、選んだカーブの動きが1拍間隔で4回ずつ追加されます。間隔は2拍・4拍にも切り替えられます。
サビの頭に目印を付ける
Marker System → 現在位置にマーカーを追加で名前を付けます。「移動」を押せば、そのフレームから編集を続けられます。

演出の作成と整理

設定済みの粒子や床を置く
便利ツールで透明な床、マテリアル付きの粒子、トレイル、Burst 100、雪を追加できます。置いた後は Inspector で好みの見た目に調整できます。
粒子数の上限を計算する
対象の階層を選び、便利ツール → Max Particles → 必要数を計算して適用。放出数・寿命・アニメーション中の値から、余裕を持たせた上限を設定します。
複数の演出を並べる
Transform で「等間隔」や「円形」を選ぶと、選択したオブジェクトをまとめて配置できます。
改名や親の変更後もキーで動かす
よく使う項目で「変更前に押す」→ 改名・移動 →「変更後に押す」の順に操作すると、クリップの参照先が更新されます。個別の修正は Path Fixer、一括改名は Batch Rename から行えます。
粒子やマテリアルをまとめて調整
粒子の設定は Particle Editor、色などの共通設定は Material Editor で、選んだ対象にまとめて適用できます。
作った演出を別の場面で使う
演出の親を選び、Effect Preset → 選択した演出を保存。次に使うときは一覧の「配置」で呼び出せます。

確認と編集の再開

観客の位置からサビを繰り返し見る
Preview で視点を選び、「区間ループ」の開始と終了を指定します。Play Mode に入らず、その区間の見え方を確認できます。
前回の編集位置に戻る
ライブの編集で対象を選び、「ライブ設定を読み込む」→「このライブの編集に戻る」を押すと、その曲のシーンが開き、前回の編集フレームに戻れます。
