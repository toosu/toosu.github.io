機能ガイド

操作マニュアルを開く →

知りたい操作を選ぶと、その手順が開きます。Unityでは Tools → Particle Live Toolkit から各機能を使えます。

準備・音合わせ演出の配置・整理プレビュー・編集の再開

準備・音合わせ

曲・Animation・Timelineの配置を一度で済ませる
Project → ライブを生成
小節や音符の秒数を暗算せずコピーする
よく使う項目 → 秒数コピー（細かい指定は Beat）
選択したキーのタイミングをまとめて拍に揃える
Beat Snap → 選択キーを拍に合わせる
再生ヘッドを1小節・4分・16分単位で前後に動かす
UnityのAnimationウィンドウで Alt と矢印キーを使用。移動幅は修飾キーで切り替えます。
選んだカーブを1・2・4拍間隔で4回ずつ追加する
よく使う項目 → 現在の範囲を取得 → ビートで4回 など（詳細設定は Animation）
オフ・オンの2つのキーを一度に打つ
Hierarchyで対象を選択 → UnityのAnimationウィンドウで Ctrl+R。現在フレームがオン、1フレーム前がオフ。0フレームではオンのみ。
同じ箇所を頭出しし直さずに聴き比べる
UnityのTimeline・Animationでスペース長押し → 離すと元の位置。目印の登録は Marker System → 現在位置にマーカーを追加

演出の配置・整理

床・トレイル・Burst・雪の初期設定を省く
便利ツール → 透明な床（Collider）、マテリアル付き Particle、マテリアル付き Trail Particle、Burst 100、広範囲に降る雪
アニメーション中の発生数を調べてMax Particlesを見積もる手間を省く
Hierarchyで対象を選択 → 便利ツール → Max Particles → 必要数を計算して適用
階層を変えた後のAnimationパスをまとめて直す
よく使う項目 → 変更前に押す → 改名・移動 → 変更後に押す（個別確認は Path Fixer）
同じ調整を複数のオブジェクトにまとめて適用する
整列は Transform、連番は Batch Rename、粒子設定は Particle Editor、マテリアル変更は Material Editor
作った演出をPrefabとして次のシーンでも使う
Effect Preset → 選択した演出を保存。呼び出すときは一覧の「配置」

プレビュー・編集の再開

観客視点で同じ区間だけ繰り返し確認する
Preview → 区間ループ
ライブを切り替えるたびにシーンと編集位置を探す手間を省く
ライブの編集 → ライブ設定を読み込む → このライブの編集に戻る
