Particle Live Toolkit

このツールは作る過程の楽しみはユーザーに残し、めんどくさい作業の効率化にフォーカスしたEditor拡張です。
パーティクルライブをワールドとして作成するために使用する事を想定したツールです。
アバターには対応していない場合があります。

v0.3.2 · Unity 2022.3

導入する

ALCOM・VCCにリポジトリを追加
URLを手動で登録する

ALCOMまたはVCCのリポジトリ追加画面に、このURLを貼り付けてください。

https://toosu.github.io/particle-live-toolkit/index.json

リポジトリを追加したら、対象プロジェクトのパッケージ一覧で「Particle Live Toolkit」をインストールします。Unityで「Tools → Particle Live Toolkit」を開き、「Project」から曲とBPMを設定してください。

旧unitypackage版をお使いの方へ

旧unitypackage版から更新すると、パッケージ管理ツールが Assets/ParticleLiveToolkit を削除します。そこに独自に追加・編集したファイルは先に退避してください。通常のライブ作品は別フォルダの Assets/ParticleLive にあります。

制作の手間を減らす操作

効率化できる作業使う場所・操作
曲・Animation・Timelineの配置を一度で済ませるProject → ライブを生成
小節や音符の秒数を暗算せずコピーするよく使う項目 → 秒数コピー（細かい指定は Beat）
選択したキーのタイミングをまとめて拍に揃えるBeat Snap → 選択キーを拍に合わせる
選んだカーブを1・2・4拍間隔で4回ずつ追加するよく使う項目 → 現在の範囲を取得 → ビートで4回 など（詳細設定は Animation）
オフ・オンの2つのキーを一度に打つHierarchyで対象を選択 → UnityのAnimationウィンドウで Ctrl+R。現在フレームがオン、1フレーム前がオフ。0フレームではオンのみ。
同じ箇所を頭出しし直さずに聴き比べるUnityのTimeline・Animationでスペース長押し → 離すと元の位置。目印の登録は Marker System → 現在位置にマーカーを追加
床・トレイル・Burst・雪の初期設定を省く便利ツール → 透明な床（Collider）、マテリアル付き Particle、マテリアル付き Trail Particle、Burst 100、広範囲に降る雪
アニメーション中の発生数を調べてMax Particlesを見積もる手間を省くHierarchyで対象を選択 → 便利ツール → Max Particles → 必要数を計算して適用
階層を変えた後のAnimationパスをまとめて直すよく使う項目 → 変更前に押す → 改名・移動 → 変更後に押す（個別確認は Path Fixer）
同じ調整を複数のオブジェクトにまとめて適用する整列は Transform、連番は Batch Rename、粒子設定は Particle Editor、マテリアル変更は Material Editor
作った演出をPrefabとして次のシーンでも使うEffect Preset → 選択した演出を保存。呼び出すときは一覧の「配置」
観客視点で同じ区間だけ繰り返し確認するPreview → 区間ループ
ライブを切り替えるたびにシーンと編集位置を探す手間を省くライブの編集 → ライブ設定を読み込む → このライブの編集に戻る

BPMに合わせて編集位置を移動

Toolkit上部でライブとBPMを確認し、UnityのAnimationウィンドウにフォーカスして押します。再生ヘッドが指定した長さだけ移動します。1小節の長さにはライブの拍数設定も反映されます。

移動幅戻る（矢印）進む（矢印）戻る（数字）進む（数字）
1小節Alt + Shift + ←Alt + Shift + →Alt + 3Alt + 4
4分音符Alt + ←Alt + →Alt + 1Alt + 2
16分音符Alt + Ctrl + ←Alt + Ctrl + →Alt + 5Alt + 6

数字はキーボード上段を使います。macOSではAltはOption、16分音符の矢印操作のCtrlはCommandです。割り当ては Edit → Shortcuts → Particle Live で変更できます。

Unity 2022.3・Unity Timeline 1.7系。VRChat用の同期再生スクリプトの自動設定にはWorlds SDKとUdonSharpを使います。
